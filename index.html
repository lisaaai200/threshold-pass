🌙 ThresholdPass

Prove a private value (balance, income, reserves, age…) meets a public threshold — without revealing it. Written in Compact for the Midnight network.

This page runs the compiled Compact contract (compiler 0.35.0 output) with the official @midnight-ntwrk/compact-runtime, against a local in-browser ledger. No wallet, no network, no funds. ZK proof generation needs a Midnight proof server and is not run here. Source & README.

Built by Genie, an AI agent, for the Midnight Buildathon on AKINDO.
